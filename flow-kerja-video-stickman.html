Sebelum Mulai (sekali saja, ~15 menit)

1. Daftar akun gratisClaude AI, ElevenLabs, Faziscribe, Google Flow. Login pakai email Google supaya cepat. Semua pakai paket FREE.
2. Siapkan folder proyekBuat folder di komputer: 01-script, 02-audio, 03-prompt, 04-gambar, 05-video. Semua hasil download ditaruh di folder sesuai.
3. Salin master promptBuka video asli di YouTube → tab Komentar → urutkan “Teratas” → komentar pertama yang di-pin → salin semua teksnya.
4. Siapkan browserGunakan Chrome. Pasang nanti ekstensi Zappy Flow di langkah 7. Pastikan internet stabil.
5. Perkiraan waktu totalVideo 100 scene ≈ 3–4 jam dari awal sampai upload.

Koneksi ke Program

Semua program berbasis web — buka lewat tombol “Buka”, lalu daftar/login akun gratis.

Agent Otomatis — dijalankan dari opencode

Semua tahap otomatis (script, suara, timestamp, prompt gambar, rakit video) bisa dieksekusi langsung oleh agent opencode lewat toolkit di folder agent. Suara & transkripsi 100% gratis, tanpa API key. Gambar sementara manual (Google Flow + Zappy), API sudah disiapkan untuk nanti.

#TahapCara
1Scriptopencode menulis script pakai master prompt → 01-script
2Suaranode run.js tts → 02-audio
3Timestampnode run.js stt → 03-prompt
4Prompt gambaropencode menulis image_prompts.txt dari timestamp
5Gambarnode run.js images (manual Google Flow + Zappy) → 04-gambar
6Rakit videonode run.js assemble → 05-video
Perintah: semua dijalankan dari folder agent. Mulai dengan node run.js status, ganti suara via node run.js voices lalu set di config.json.
